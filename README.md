# cbs-ibs-prototipo

Protótipo navegável do sistema de captura de notas fiscais (CBS/IBS para produtores rurais).

**Acesse: <https://fabiofranca.github.io/cbs-ibs-prototipo/>**

## Dados fictícios

Todos os dados exibidos (produtores, documentos, chaves de acesso, notas, certificados) são **totalmente fictícios** e servem apenas para demonstração. Nada aqui vem de produtor, nota ou certificado reais, e o protótipo não consulta a SEF-SC nem nenhum banco.
